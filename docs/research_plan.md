# План исследования

## Тема

Перенос группового знания в нейронных процессах для cold-start рекомендаций.

## Исследовательская гипотеза

Для отдельных новых пользователей групповое знание может ухудшать рекомендации по сравнению с моделью, использующей только личную историю.

## Базовые модели

- TaNP, WWW 2021;
- FANP, IEEE TKDE 2024.

## Ближайшие этапы

1. Воспроизвести TaNP на доступном наборе LastFM.
2. Зафиксировать протокол, метрики и время обучения.
3. Подготовить MovieLens по протоколу статьи и повторить baseline.
4. Реализовать FANP или максимально близкий воспроизводимый вариант.
5. Сравнить модели при разном объёме истории нового пользователя.
6. Проверить, может ли групповой компонент ухудшать качество для отдельных пользователей.
7. По результатам анализа сформулировать и проверить изменение механизма адаптации.

Пункты 6–7 пока являются исследовательским направлением, а не установленным результатом.
