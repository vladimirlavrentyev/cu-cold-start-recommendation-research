# План рисунков

1. **Главная схема проекта.** Перенос группового знания к новому пользователю и возможный высокий вес нерелевантного центроида.
2. **Кривые обучения baseline.** Loss и NDCG по эпохам для проверки корректности запуска.
3. **Качество при разной длине истории.** Сравнение TaNP и FANP при фиксированном протоколе.
4. **Пользовательский анализ.** Распределение изменения качества после добавления группового компонента.
5. **Анализ мягкого сопоставления.** Связь весов центроидов с изменением качества рекомендаций.

Первый рисунок используется в one-slide докладе. Остальные строятся только после фиксации экспериментального протокола.
