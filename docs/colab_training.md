# Обучение TaNP Gating-FiLM на Colab T4

## Что именно обучается

На каждом датасете обучается независимый TaNP Gating-FiLM с seed 2020 и
авторскими гиперпараметрами из `third_party/TaNP/train.sh`. Модели запускаются
последовательно, поэтому одновременно в памяти находится только одна модель.

Итоговые каталоги:

- `artifacts/runs/tanp_gating_film_lastfm_seed2020`;
- `artifacts/runs/tanp_gating_film_movielens_seed2020`;
- `artifacts/runs/tanp_gating_film_gowalla_seed2020`.

## Порядок запуска

1. В Colab выбрать `Runtime -> Change runtime type -> T4 GPU`.
2. Открыть `notebooks/tanp_gating_film_colab.ipynb`.
3. Последовательно выполнить ячейки сверху вниз.
4. Проверить три индивидуальных CSV и общую summary-таблицу.
5. Скопировать checkpoints и таблицы на Google Drive последней ячейкой.

## Что считается успешным базовым запуском

- CUDA обнаружена до начала обучения;
- для каждого датасета создан отдельный `.pt` checkpoint;
- каждый лог содержит 100 эпох и девять ranking-метрик;
- summary-таблица содержит по одной финальной строке на датасет;
- `run_metadata.json` фиксирует команду, seed, декодер и устройство.

## Научное ограничение

LastFM использует опубликованные авторами данные. MovieLens и Gowalla авторы не
выложили в подготовленном виде. Особенно для Gowalla полученный результат
относится к зафиксированной нами реконструкции протокола, а не к неизвестному
авторскому сплиту.
