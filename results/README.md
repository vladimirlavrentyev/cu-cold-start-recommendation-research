# Результаты

Здесь хранятся компактные таблицы, необходимые для статьи и проверки выводов. Checkpoints и подробные логи остаются в локальной папке `artifacts/runs/`.

Каждый файл результатов должен быть связан с конфигурацией запуска через одинаковый `run_name`.

Файл `tanp_gating_film_seed2020_summary.csv` содержит результаты последней,
сотой эпохи TaNP Gating-FiLM на LastFM, MovieLens-1M и реконструированном
Gowalla. Для всех запусков использован seed 2020. Результат Gowalla подходит
для последующих сравнений моделей в одинаковом протоколе, но не является
точной репликацией таблицы статьи из-за отличий подготовленной выборки. В CSV
эта эпоха записана как 99, поскольку счётчик эпох начинается с нуля.
