# Данные

Эта папка предназначена для датасетов и промежуточных представлений, которые не публикуются в Git.

Подготовка всех наборов:

```bash
python scripts/prepare_datasets.py --dataset all --seed 2020
```

После выполнения создаются `data/raw`, `data/processed/movielens_1m` и
`data/processed/gowalla_reconstructed`. LastFM извлекается из авторского
`third_party/TaNP/data.zip` в `third_party/TaNP/data/lastfm_20`.

Подготовленный набор содержит словари взаимодействий, списки непрерывных
идентификаторов и `manifest.json` с источником и параметрами обработки.
MovieLens использует полный MovieLens-1M. Gowalla помечен как reconstructed,
поскольку точный авторский сплит и negative sampling не опубликованы.

Для каждого нового набора данных нужно зафиксировать:

- источник и лицензию;
- версию или дату загрузки;
- контрольную сумму исходного архива;
- правила фильтрации;
- способ формирования support- и query-наборов;
- команду воспроизводимого препроцессинга.

Подготовленный авторский LastFM baseline пока хранится локально в `third_party/TaNP/data/lastfm_20` и также исключён из Git.
